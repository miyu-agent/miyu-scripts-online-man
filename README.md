# Online man pages

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `online_man`, which searches and reads Linux man pages online. The data comes from the Arch Linux manual site <https://man.archlinux.org/>, which carries the manuals of every package in the official Arch repositories, in several languages; if that site does not have the page you want, the tool looks it up on <https://man7.org/>.

The tool takes these parameters:

| Parameter | Description |
|---|---|
| `action` | The operation to perform: `search` searches the manuals, and `read` reads one manual page. |
| `query` | For `search`: the keywords to search for. The tool searches both the page names and their one-line descriptions. |
| `name` | For `read`: the name of the manual page, such as `ls` or `pacman.conf`. You can also write it as `printf(3)`. |
| `section` | The manual section, such as `1`, `3`, `5`, `8` or `3p`. If you leave it out with `read`, the manual site picks the commonly used section. |
| `language` | The language of the page, such as `en`, `zh_CN`, `ja` or `de`. The default is `en`. If the page is not available in that language, the tool returns the English version and says so. |
| `limit` | For `search`: the number of results to list, from 1 to 50. The default is 10. |
| `find` | For `read`: start reading at the first line that contains this text, for example an option such as `--color` or a section such as `EXAMPLES`. |
| `offset` | For `read`: the character to start reading from, so that you can continue where the last read stopped. |
| `max_chars` | For `read`: the number of characters to return at a time, from 2000 to 60000. The default is 12000. |
| `format` | The output format. `md` (the default) is for people and the AI to read; `json` is for code, for example when you pipe the result of `miyu call` into `jq` or Python. Errors are JSON as well: `{"ok": false, "error": …}`. |

If a page is long, the tool returns one part at a time and writes the `offset` of the next part at the end. The English version is read from the manual site's plain text; other languages are read from the web page and converted to text, because the site's plain text drops every non-ASCII letter. The tool uses only the Python standard library.
